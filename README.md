# fireless-war-web

## 中文

「願浮沉2:無火戰爭」前端網站。

搭配後端 API:[`router-backend`](https://github.com/beethoreven/router-backend) 的 `apps/fireless_war/`,掛在 `/fireless-war`

透過 GitHub Pages 從本 repo 根目錄部署。

技術細節、架構決策見 [`fireless-war`](https://github.com/beethoreven/fireless-war#專案報告) 裡完整的專案報告。

## English

Frontend for *Dreaming of a damp squib 2 - Fireless War*.

Pairs with the backend API: [`router-backend`](https://github.com/beethoreven/router-backend), `apps/fireless_war/`, mounted at `/fireless-war`

Deployed via GitHub Pages from this repo's root.

For technical details and architecture decisions, see the full project report in [`fireless-war`](https://github.com/beethoreven/fireless-war#project-report).
